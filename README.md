# 🧩 Memory Game (Игра на развитие памяти)

Классическая браузерная карточная игра **Memory Game**. Цель игры — найти все пары одинаковых карточек за минимальное количество ходов или отведенное время. Проект создан на чистом JavaScript без использования сторонних библиотек и сборщиков.

## ✨ Особенности (Features)

- **Динамическая генерация:** Карточки каждый раз перемешиваются случайным образом перед началом игры.
- **Анимация переворота:** Плавный и приятный 3D-эффект переворота карточек на чистом CSS.
- **Учет прогресса:** Подсчет количества сделанных ходов (кликов) и таймер времени.
- **Полная адаптивность:** Игра одинаково хорошо работает на смартфонах, планшетах и компьютерах.

## 🛠️ Стек технологий (Tech Stack)

- **Разметка:** HTML5 (семантическая структура)
- **Стилизация:** CSS3 (Flexbox, CSS Grid для сетки карт, `@keyframes` для анимаций)
- **Логика:** Vanilla JavaScript (ES6+, работа с DOM, таймеры, алгоритм случайной сортировки Фишера-Йетса)

## 🚀 Как запустить игру локально

Проект не требует установки Node.js, NPM или настройки серверов.

### Способ 1: Быстрый запуск

1. Клонируйте репозиторий на свой компьютер:
   ```bash
   git clone https://github.com{ваше-имя-пользователя}/{имя-репозитория}.git
   cd {имя-репозитория}
   ```
2. Найдите в корневой папке файл `index.html` и дважды кликните по нему. Игра откроется в вашем браузере.

### Способ 2: Через Live Server (Рекомендуется)

Если вы хотите изменять код и сразу видеть изменения без перезагрузки страницы:

1. Откройте папку проекта в **VS Code**.
2. Установите расширение **Live Server** (если еще не установлено).
3. Нажмите на кнопку **"Go Live"** в правом нижнем углу редактора. Игра откроется по адресу `http://127.0.0.1:5500`.

## 🎮 Правила игры

1. Нажмите на любую карточку, чтобы перевернуть её и увидеть изображение.
2. Затем переверните вторую карточку.
3. Если изображения на карточках **совпадают**, они остаются открытыми.
4. Если изображения **разные**, карточки переворачиваются обратно через небольшую паузу.
5. Игра завершается, когда будут найдены абсолютно все пары.
